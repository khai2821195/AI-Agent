# Gemini Global Memory

모든 프로젝트에 공통으로 적용되는 개인 선호도 및 컨텍스트.  
Gemini Code Assist의 `~/.gemini/GEMINI.md` (Global Memory) 파일에 대응합니다.

> [지니 보완] 원본은 Gemini Code Assist가 자동 생성한 빈 전역 메모리 템플릿. 실제 사용 중인 선호도를 반영하여 보강함.

---

## 개인 선호도

| 항목 | 값 |
|------|----|
| 응답 언어 | 한국어 |
| 주요 도구 | Obsidian, n8n, Claude Code |
| IDE 환경 | VS Code + Gemini Code Assist |
| 협업 스타일 | 자율적 판단 후 결과 보고 선호 |

## 자주 사용하는 스택

- **자동화:** n8n (self-hosted, `https://n8n.math4u.co.kr`)
- **DB/백엔드:** Supabase (self-hosted, Oracle Cloud)
- **지식 관리:** Obsidian 볼트 (`V:\Obsidian\`)
- **AI 오케스트레이션:** Claude Code (CLI), Gemini Code Assist

## 프로젝트 컨텍스트

- 사업: DCT (온라인 쇼핑몰) + Math4U (수학학원)
- 학원 자동화 시스템 운영 중 (Notion + n8n + Alimtalk)
- TAIN 프로젝트 (SaaS 학원관리 플랫폼) 개발 중

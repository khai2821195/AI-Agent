# Claude CLI 설정

Claude Code CLI (`claude`) 설정 파일 관련 참고 노트.

> [지니 보완] 원본은 `Claude CLI Settings.json` (Inbox 보관). 민감 정보 없음. 설정 내용을 참고용으로 정리함.

---

## 현재 설정

| 항목 | 값 | 설명 |
|------|----|------|
| `autoUpdatesChannel` | `latest` | 자동 업데이트 채널 (안정 최신 버전) |

---

## 설정 파일 위치

| 파일 | 위치 |
|------|------|
| CLI Settings | `%APPDATA%\Claude\claude_cli_settings.json` (추정) |
| Desktop Config | `%APPDATA%\Claude\claude_desktop_config.json` |
